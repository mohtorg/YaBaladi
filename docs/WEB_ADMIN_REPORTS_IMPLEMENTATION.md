# يا بلدي — بوابة الإدارة والتقارير عبر المتصفح

## ما تم تنفيذه
- إضافة دعم Web إلى مشروع Flutter عبر مجلد `web/`.
- إبقاء بوابة المصادقة والصلاحيات نفسها للأدمن والمشرف؛ لا يوجد مسار إداري منفصل يرفع الصلاحيات.
- تعطيل الدخول السريع المعتمد على MethodChannel تلقائيًا على Web حتى لا يمنع فتح لوحة الإدارة من Chrome أو أي متصفح حديث.
- إضافة طباعة تقرير عبر نافذة المتصفح `window.print()` عند امتلاك `reports.print`.
- إضافة تصدير التقرير في Web كملف نصي عند امتلاك `reports.export`، مع إبقاء التصدير في Android كنسخ إلى الحافظة.
- تطبيق نطاق المشرف على استعلامات التقارير وفق `scope.all` وحقول المحافظة/المدينة/التصنيف/مجموعة الأماكن.
- إبقاء `reports.read` شرطًا لعرض التقارير، و`reports.export` و`reports.print` صلاحيتين مستقلتين.
- إضافة إعداد Firebase Web وتهيئة Google Sign-In Web.
- إضافة إعداد Firebase Hosting مع rewrite إلى `index.html`.

## ملاحظة تشغيلية
يجب تنفيذ `flutterfire configure` على جهاز التطوير/الإطلاق لإعادة توليد `firebase_options.dart` بالقيمة الرسمية لـ Web App ID الخاصة بمشروع Firebase قبل نشر نسخة Web العامة. لا يتم تنفيذ Firebase deploy ضمن هذه المرحلة.

## صلاحيات التقارير
- Admin: يتجاوز نطاق المشرف وفق Custom Claim `admin=true`، وتظل أزرار التصدير والطباعة ظاهرة فقط عند امتلاك الصلاحية المناظرة، مع اعتبار الأدمن الأعلى مخولًا.
- Moderator: التقرير لا يتجاوز `scope` الخاص به، والطباعة/التصدير لا يظهران إلا عند امتلاك `reports.print` / `reports.export`.
