# يا بلدي — هندسة الموقع الجغرافي والاتصال

## الهدف
توحيد التعامل مع GPS والموقع والعنوان والاتصال في خدمة مركزية بدل تكرار منطق الصلاحيات داخل كل شاشة.

## 1) موقع التاجر
عند إضافة/تعديل المكان:
- بحث العنوان تلقائيًا عبر geocoding.
- استخدام موقع الجهاز الحالي عبر GPS.
- الإحداثيات Lat/Lng قابلة للتصحيح اليدوي كخطة احتياطية.
- عند استخدام الموقع الحالي يمكن تعبئة العنوان من الإحداثيات إذا توفر reverse geocoding.
- لا يتم حفظ موقع الجهاز الشخصي تلقائيًا في Firestore.

## 2) موقع المستخدم والضيف
`LocationService` هو المصدر الموحد:
- يطلب الصلاحية عند الحاجة فقط.
- يعيد الموقع الحالي من GPS.
- يستخدم آخر موقع معروف من الجهاز عند تعذر القراءة الفورية.
- يحتفظ بآخر إحداثيات محليًا فقط لتحسين التجربة عند انقطاع الشبكة.
- يوفر stream اختياريًا للتحديث أثناء الشاشات التي تحتاج حركة المستخدم.

## 3) التحديث أثناء الحركة
- شاشة «أماكن قريبة» تعيد حساب المسافات وترتيب الأماكن أثناء تحرك المستخدم.
- شاشة «رحلة اليوم» تعيد ترتيب الأماكن حسب المسافة أثناء وجود المستخدم داخل الشاشة.
- لا يوجد طلب لتتبع الموقع في الخلفية.
- التحديث يعتمد على مسافة تغير لا على قراءة GPS لكل ثانية لتقليل استهلاك البطارية.

## 4) انقطاع الشبكة
يتم فصل مفهوم GPS عن الإنترنت:
- GPS قد يستمر في إعطاء موقع الجهاز حتى مع فقد الشبكة.
- آخر موقع معروف محفوظ محليًا يستخدم كبديل عند تعذر القراءة الفورية.
- بيانات الأماكن التي سبق تحميلها يمكن قراءتها من Firestore cache.
- إذا فشل طلب Firestore بسبب الشبكة، `PlaceService` يجرب المصدر المحلي `Source.cache`.
- البحث عن العنوان يحتاج خدمة geocoding؛ عند تعذرها يبقى GPS والإدخال اليدوي متاحين.
- لا تُعرض مسافة مخترعة؛ عند عدم وجود موقع صالح تعرض القائمة بدون مسافات.

## 5) الخصوصية
- لا يوجد background location.
- لا يتم رفع إحداثيات المستخدم الشخصية إلى Firestore بواسطة `LocationService`.
- التاجر يحفظ إحداثيات **المكان التجاري** ضمن مستند المكان، وليس موقع الجهاز الشخصي.

## 6) نقطة التطوير التالية
عند توفر Flutter CLI على جهاز التطوير:
1. `flutter pub get`
2. `flutter analyze`
3. اختبار صلاحيات الموقع على Android: denied / while-in-use / deniedForever.
4. اختبار GPS مع الإنترنت وبدونه.
5. اختبار geocoding بعنوان عربي وعنوان إنجليزي.
6. اختبار الانتقال أثناء الحركة في «أماكن قريبة» و«رحلة اليوم».
7. اختبار Firestore cache بعد تحميل الأماكن ثم فصل الشبكة.
